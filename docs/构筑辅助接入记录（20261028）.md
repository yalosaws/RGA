# 构筑辅助接入记录（2026-10-28）

已按用户选定的紧凑清单接入 RGA 源码：工具 → 构筑辅助。读取“我的存档”当前使用的同一份导出串和时间；支持中英文名称、研究代号搜索、同类数值筛选、游戏说明、已拥有状态及自身公式值。目录包含 2059 项升级，也保留没有统一加成方法的研究。

后续已增加“读取游戏快照”和每次实时试算前重新采集，见《实时计算快照接入与验证（20261028）》。下面保留存档模式的接入与验证记录。

顶部显示建筑与助手合计的总产出、建筑产出、助手收入、回魔；可展开精确数值、来源和验证范围。自身公式值保留客户端原始单位，不把助手数量误标成百分比；说明中的飞升后效果与原始公式值可能不同。

试算调用 `rg_growth.Simulation` 的真实购买、施法入口，每次恢复到同一份存档的内存检查点（包括对象、静态字段、容器和随机数位置），保留已计算的客户端缓存。金币、魔力变化是动作前后的净变化。仅比较瞬时状态，不推演未来持续施法、随机事件期望值或在线活动服务器状态。SID 为 0 的商店/活动按钮不具备唯一持久身份，保留查询，暂不试买。

计算在独立子进程中运行；不持有游戏存档文件的写入接口。存档更新后清除旧结果，并用内容与时间的摘要拒绝过期请求。模块和索引的 SHA256 必须一致；当前计算模块支持最高存档格式 58，更高版本明确报错，避免客户端 load 提前返回后显示初始化默认值。

程序语言函数不能被汉化直接替换：部分客户端计算按翻译后的名称查询对象。接入层保持引擎原文，最后根据汉化文本模板翻译说明，避免改变计算语义。

## 文件与运行

- `app/build_engine.py`：受限操作接口、后台进程、目录和公式查询。
- `app/rg_app.py`：`build_calculate` 接口及 `--build-worker` 进程入口；源码预览模式单独使用 `%LOCALAPPDATA%/RGA-source-preview`。
- `scripts/build_tools.html/css/js`：紧凑清单和即时试算界面，由 `build_html.py` 生成，未手改 `build/app`。
- `scripts/prepare_engine.py`：从已核对的模块和索引准备 `build/calculation`；运行时不需要 ffdec。
- `scripts/simulation_state.py`：游戏状态回滚与随机数位置恢复；程序试算和字节码差分共用。提速及客户端 tick 机制见《计算性能与客户端时间推进核对（20261028）》。
- `app/build_exe.py`：已加入计算资源和子进程模块；本轮未执行打包，冻结版仍须在实际打包时验证。
- `updater.SHELL_API` 已升为 5：2 增加计算接口，3 增加完整存档变化推送，4 增加轻量只读内存接口，5 增加实时计算快照；避免新界面调用旧程序缺少的功能。
