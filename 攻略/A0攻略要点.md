# Realm Grinder A0 攻略要点（R1–R39）

> 依据：官方 Discord #pre-ascension 置顶的 "A0 Guide"（作者 ensteffahn，2026-05-27），英文原文见 `资料/A0 Guide.txt`。
> 这是用中文整理的要点，不是逐句翻译；具体数值以游戏内显示为准。配套 build 来自同一置顶的 **A0Templates.txt**（适配 v4.3.11）。
> 原作者默认你在 PC 上玩，但绝大部分内容也适用于手机。

## 记号说明

- **阵营代码**：FR 妖精、EL 精灵、AN 天使、GB 哥布林、UD 不死族、DM 恶魔、TT 泰坦、DD 德鲁伊、FC 无面者、**DN 矮人、DW 卓尔**。后面加数字是该阵营第几个升级（1–9，由便宜到贵），如 DM7。
- **血统 + 阵营**：血统写在前面，例如 FCGB = 无面者血统的哥布林，ELEL = 精灵血统的精灵。
- **研究代号**：研究所首字母加数字，S（法术）、C（工艺）、D（神圣）、E（经济）、A（炼金）、W（战争），如 E300。模板代码里也用这套写法。
- **挑战代号**：阵营代码 + C + 序号，例如 DMC1 = 恶魔挑战 1，DWC1 = 卓尔挑战 1。

## 第 1 部分：R1–R3

这份攻略接着 R0 攻略（Beginner Guide）讲，默认你已经照着做完，包括在 R0 最后拿到 **Coin Pillage**。

### 进 R1 时应该已有的隐藏奖杯

Leet、Unitary、Building Hater、Grand Diplomat、Exchange Master、Assistant Squasher、Rewind、Faction Grinder、Spellfury、Speed Run、Premeditation、Need A Head Start?、Realm Digger、Mathematician、Unlimited Mana、glho kohhl snod、Suggestion Master、Rule 'dis、Advisor Insight，以及可选的 Mana Matrix、Mana Waste。

**缺哪个就在 R1 补上。**

正常玩下去迟早会拿到的：Lucky Neutral、Perfectly Good、Diabolical Evil、Master Archeologist、Beard Carpet（用矮人打一局长的）、Fast Forward、Because I Like To Grind。

**Equality**（可选）：善良、邪恶、中立三个阵营各用至少 8 小时，三者相差不超过 1 小时。适合在没空玩一整天的 R 里挂着拿，攻略后面不假设你有它。

### 没拿到 Coin Pillage 的话

R1–R3 就像加速版的 R0。用哪个阵营可以看 Discord 置顶里的 **A0plot** 图表，它也能用来快速查什么时候用什么 build。当然，也可以在 R1 补拿 Coin Pillage。

A0plot 里还有"离线时做什么"一栏，其中前两项对 A0 有用，**一定要找时间做**：
- 离线挂 5 小时德鲁伊
- 离线挂 5 小时无面者

### 拿到了 Coin Pillage 的话：整个 R1 都用恶魔

| 宝石数量 | 打法 |
|---|---|
| 0 – e10 | 打很短的局：不等 Demon Alliance（要 500 FC），放一两轮法术连招就退位 |
| e10 – e17 | 可以拿 Coin Pillage 了。值得买的只有 Demon Alliance 和基础阵营的 Heritage（5k FC），其他不买 |
| e17 以上 | 可以用卓尔了。买齐卓尔的所有升级和中立阵营的 Heritage。声望阵营的 Heritage 暂时太贵，不划算 |

### R2：解锁挑战

挑战大多先不管，**只在 R2 末尾做恶魔挑战 1**：
- 挑战期间不能买 gem power 和 R power。所以这时候可以去选项里关掉"全部购买升级"，这样还能继续用全部购买。
- 买齐恶魔所有升级，然后等几分钟攒 FC 就能完成。

完成后推进会明显变快。

### R3

R3 一开局就能拿到矮人和卓尔的 FC。缺点是用恶魔会稍慢一点，但总体上更方便。

**R3 目标：打到 e34 宝石，解锁佣兵（Mercenary）。**
- 有 Coin Pillage：用恶魔刷宝石，顺便就到了。
- 没有：用哥布林慢慢打。

## 第 2 部分：Lore 遗物（该挖哪些）

下面的概率用**千分比（‰）**表示：前几个 R 一局大约能挖 1000 次，所以"x‰"约等于每个 R 能挖到几个。准确概率要在游戏里看。

- 外部工具 "lara crypt" 能帮你刷遗物，攻略不用它，你可以自己用。
- **挖掘前建议先导出存档**，没挖到可以读档重来。
- 恶魔根本不需要挖掘就能打到佣兵阶段（约 e33 宝石），所以这时候正好去刷遗物。每个 R 的末尾也是刷遗物的好时机。

### 通用遗物（前 5 个）

| 遗物 | 难度 / 说明 |
|---|---|
| Rough Stone | 挖掘的那一局有 2% 概率。最好是哪次碰巧挖到；硬刷也行（挖掘次数低时反复退位），但很烦。大约 R25 才用得上 |
| Scarab of Fortune | R0 攻略讲过，有用，不难 |
| Chocolate Cookie | 致敬 Cookie Clicker，最简单的遗物 |
| Fossilized Rodent | 本 R 每小时约 0.05‰（按挂机时每秒 7 次点击算）。升级很好但没法速刷；好在一直能挖，粗略估计过了最初几个 R 后，每玩一天约有 50% 机会挖到。知道这个 R 会打很久（比如要过夜）的话，可以先留着挖掘次数，提高拿到它的机会 |
| Power Orb | 3–10‰，很简单，有佣兵后更容易 |

## 第 3 部分：R3–R15 佣兵

**先导入 A0Templates.txt**，后面几乎所有 build 都在里面。点模板的编辑按钮可以看到模板代码：佣兵能选 12 个种族升级和 2 个种族法术。

佣兵升级要花 FC（有些还要花钱币），第一个约 1k，最后一个超过 1M。佣兵 build 靠前面的升级多赚 FC 再买后面的，**没法一次导入买齐**。

### 刚解锁佣兵（R3）

用**中立佣兵**，依次跑：
1. **Coin Pillage build**（就算已经有 Coin Pillage 也跑）：顺带解锁 Harlequin。多待几分钟攒宝石，同时买到 1500 个皇家兑换，拿 **Exchange Lord**。
2. **Lucifer build**。
3. **自动施法 build**：拿齐自动施法系列奖杯，直到 Efficient Autocasting，大约半小时。之后回魔够高时，点魔法池旁边的铜色预设就会自动放所有法术。
4. 还没有 **Mana Matrix** 的话补上，R0 攻略里有一种拿法。
5. **Helden Sterben Nicht**：退位后按顺序加入 佣兵 → 不死族 → 天使。判定有时不灵，每局多待几秒；没成功就再来。

佣兵阶段刷宝石用 **Mana Fairies build**（低宝石版已经够强）。这时可以借佣兵的强度顺手拿几个普通奖杯，也可以直接继续转生。

**转生进 R4 时一定要处在佣兵状态**，拿 **Mercenary Spirit**。错过了就下个 R 补，别忘了。

### R4–R15

- **R4** 的挑战可以不管。
- **R6** 解锁声望阵营挑战。DWC1 用恶魔打，奖励不是必需，但没加强 Perfect Combo 时比较花时间，建议在**过夜那一局之后**做，最好等到 R7。
- **R7 解锁血统（Bloodline）**，R 会变得非常快。
  - **精灵血统（Elfline）**是最通用的血统，大幅提高 FC 获取，恶魔局也能买到更多升级。
  - Mana Fairies 用**无面者血统**冲产量，但第一局佣兵先用精灵血统起步比较顺。
  - 有了精灵血统，可以直接用高宝石版 build，低宝石版基本不用了。
- 不是速通的话，这时应该已经解锁无面者，**买无面者 Heritage**，最后几个佣兵 R 很有用。
- 之后几个 R 会解锁更多 R power，新挑战可以先不管（觉得简单就做）。
- **R12**：解锁遗物 **Know Your Enemy, Part I**。进佣兵时像 R3 一样先跑 Coin Pillage build 来拿它。
  - 这时 Mana Fairies 开始变慢，高宝石阶段改用 **Necro Lightning**（Mana Fairies 硬撑到底也行）。
  - Necro Lightning 每个 R 要先做两个加成：离线约 5 分钟加强 Trade Lords（中立专属佣兵升级）；再快速跑一下**邪恶建筑加成 build**，提高 UD2 和 DW5 的数值。
  - 这个 build 有 Lightning Strike，**只在打中 Farm 或 Inn 时放连招**。
- 按这个打法过 R15 应该没大问题。

## 第 4 部分：R16–R23 研究

### R16：解锁研究

- 一进 R16，先用恶魔拿 **Vanilla Flavour Juice** 遗物（很简单）。它只加强**基础阵营**（不含声望阵营），所以卓尔先别买。
- 保持挖掘次数低，约 e50 宝石时用邪恶建筑加成 build 挖 **Voodoo Doll** 遗物（没挖到就高宝石时或下个 R 再试）。然后用佣兵打到约 e72。这是最后一个需要 Necro Lightning 的 R。
- 先做几个很快的挑战：**FRC1、FRC2、ELC1、UDC1、UDC2**；碰到 GBC1（随机出现）后再做 GBC2。

到 R16 就能解锁研究，但要让研究真正撑得起产量，得先完成很多零碎的解锁，分三步：

**第 1 步：解锁研究所**
依次用妖精、精灵、天使、哥布林、不死族、恶魔，解锁各自的独特建筑和研究所。**不要用矮人和卓尔。** 每解锁一个研究所，该阵营产能 +100k%。解锁后**立刻退位**，先别进研究页。

**第 2 步：用哥布林升级研究所**
- 用 FCGB。6 个研究所各能升 136 级，越升越贵，可以用顶部的全部购买。
- 研究图标含义：无符号 = 已解锁可买（买不起时变灰）；**x** = 已解锁但当前阵营不能用；**!** = 未解锁，当前阵营能解锁（会显示条件）；**?** = 未解锁，当前阵营也解锁不了。
- 每局每个研究所最多买 4 个研究，现阶段不算限制，能买就买。
- 研究所全升到至少 80 级 → 退位用 **GBGB**，解锁 C80、E80。
- 回 FCGB，研究所能升到 120，途中解锁 novice researcher → 快速退位用 **UDGB** 解锁 W120（加强非独特建筑，即除 Goblin Bank 外的建筑，矮人血统更能加强这些建筑，所以换矮人血统）→ 用 **DNGB** 把研究所升满。

**第 3 步：解锁全部研究**

| 组合 | 解锁 |
|---|---|
| DDAN | D55、A55（顺带 S10、D50） |
| GBFR | A105、S135（顺带 C10） |
| DDUN | A50、A10（多半还有 A135） |
| DDEL | E25、C50（顺带 W10） |
| FCFR | S50 |
| DDGB | E50 |
| DDDM | D10 |

剩下的是要挂时间的研究，用一局佣兵基本拿齐：
- 邪恶、精灵血统：FR4、EL1、EL8、AN1、AN5、GB5、DN4，法术 Hellfire Blast、Fairy Chanting（其余随意）。
- 跑约 2 小时，其中至少 1 小时离线。然后依次用 DM、UD、FR 实际解锁，最后用精灵。如果还差点击数或 Elven Luck，正好做 ELC2（要 50 分钟），否则可以拖到 R18。

全部解锁后就能用 **R16 FCGB build** 刷产量。Vanilla Flavour Juice 的 +2500% 只在开局前 5 分钟有效，所以基础阵营研究 build **一局一般打 5 分钟或更短**，打几局就能转生。

### R17

- 研究所的 +100k% 只加基础阵营，满级卓尔也比纯恶魔强不了多少，所以**完全跳过卓尔**，佣兵阶段之前一直用恶魔。
- 研究都解锁了，**e66 宝石就能进研究**（直接用 R17 DNGB build），用 Mana Fairies 很容易到。
- 每个 R 研究点上限会提高。R17 的新研究前置都已满足，会自动解锁。有了这些新研究，R17 不会花太久。
- R17 末尾适合做 **DMC2**：用研究 build 每种买 100 个兑换，共 6×100 + 66（跳过恶魔兑换）。

### R18：集中做挑战

这个 R 没有新研究，按顺序做：
1. 约 e75 宝石，用 GBDM 做 **DMC3**（简单，奖励好，回到 e78 更快）。
2. e78 用普通 R17 build 做 **GBC3**，奖励很强，对非哥布林阵营等于 TC 翻倍。
3. 没做 ANC1 就做（挂 10 分钟），再做 **ANC2**（有 A150 后很快）。
4. 用德鲁伊血统做 **UDC3、ELC3、FRC3**，都简单。各阵营最终挑战会解锁一个法术升级。
5. Goblin's Greed 现在按本 R 的 FC 算，可以加强（基本只在 R18 用得上）。刷 FC 最快的还是佣兵：
   - 中立、精灵血统：EL1、AN1、AN8、GB3、GB5、GB7、UD7、DD3、DD4、FC5、DN4、DW7，法术 Lightning Strike、Fairy Chanting（不用跑太久）。
6. 刷到 e80 做最后的 **ANC3**。不能买 Heaven's Domain，很多研究没用，用这套：
   S30、S105、S150、C25、C80、C120、C150、D55、D135、D150、E30、E145、E150、A105、A120、A135、A150、W120、W135、W150
   奖励下个 R 才用得上，但拿齐基础阵营挑战奖杯有 +25% 产能。

再打 1–2 局 5 分钟就能转生。这时 **Faction Run**（5 分钟内 150 万 FC，不用 gem power 和法术）也不难：精灵血统恶魔，配好 build 等大约 4 分钟。

### R19–R23

- **R19**：R18 那批挑战给了全局加成，推进更快了；两个种族法术也都加强了，佣兵阶段尤其明显。低宝石阶段继续用 R17 DNGB build 1–2 个 R，直到 R20+ build 更强。
  - 轮流用各阵营解锁新研究。**W180** 要施放 150 次 CtA，最快的方法是**反复退位**：把游戏窗口缩小，退位后马上按 2 放 CtA（作者说这是唯一推荐刷退位的大研究）。
  - **S175** 很强，改用**精灵**。Elven Luck 有 25% 概率时，**Lucky Clover** 遗物几乎白送。
  - 精灵研究 build 回魔低，主要收入来自 Elven Luck 而不是 TC。普通法术放铜色，**TC 放银色**，让所有法术一直开着触发 Elven Luck。
  - R19、R20 偏慢。第 5 分钟手动点击触发更多 Elven Luck 能快一点；打长一点的局积累点击数也可以，只是不是最优。
- **R20**：和 R19 一样。这时适合拿 **That Excavated Quickly**（开局 30 秒内挖 1000 次）。**D205、W205 先别买。**
- **R21**：E230 很强，改用**恶魔**。用恶魔拿 W205、S215；买 A25 并持续放 Hellfire Blast，否则这个 R 会偏慢。
- **R22**：有几个强研究，又快起来了。改用**不死族**。接近转生宝石时，花 5 分钟中的 1 分钟加强 UD9 值得，太早做反而麻烦。
- **R23**：同 R22。这个 R 或下个 R 用 ELEL 待 15 分钟解锁 **S270**，或离线 1 小时也会解锁。

## 第 5 部分：R24–R31 中立研究

### R24（最重要的一个 R）

1. 低宝石时快速切一次中立，解锁 **Ancient Cocoa Bean** 遗物（4.3.12 起要求 R24）。
2. 到 e87 宝石，挖到 1500 次拿 **Key to the Lost City**。用 **DDTT 解锁中立研究**。
3. 用 R24 DDTT build 解锁 **E300**，拿 **Businessman**。它是 6 个"加研究槽位"隐藏奖杯中的第一个，6 个这个 R 全拿。之后还能拿 W290。
4. 用 **UDFC**：导入泰坦 build 就能解锁 W300；手动买 E135，就能拿 D290。
5. 反复退位刷 **S300**（只要 8 次施法），没有 **Faceless Overmind** 的话也会顺便拿到。
6. 用带 E135 的 **GBDD** 快速拿 E290 和 D300，空位用 R26 德鲁伊 build 的研究补满。

**中立挑战**
- **TTC1** 比较麻烦。最简单的做法是只买：gem power、精灵血统、Assistant Squasher、6 个建筑升级（正好 13 个助手）、Coin Pillage、Lightning Storm；皇家兑换正好买 169 个（8×20 + 9）。
- **DDC1** 多半已经自动完成，没完成就把建筑数量平均一下。顺便做 **DDC2**。
- **FCC1–3** 都很简单。

之后用**泰坦**刷宝石，不用急，反正要等 C300：
- Ancient Cocoa Bean 持续 15 分钟，可以打更长的产量局。
- 这个 R 和下个 R 都要面对 Lightning Strike 的随机性。
- 挖到 2000 次后可以挖 **Ancient Device**。把 E30 换成 E270 能多挖，也适合顺便挖泰坦 1 遗物。
- 运气好可以早买 C200，否则要等 C300 解锁额外研究槽位，这个 R 没拿到就下个 R 再试。
- 转生宝石到了但 C300 还没好，就先做 **TTC2、TTC3**（TTC2 算自动点击，不用手点）。

### R25–R31

- **R25**
  - 用 DDAN 解锁 D320。宝石够高后用 ELTT 做 **TTC4**（约 10 分钟）。
  - **DDC3**：把 Stone Pillar 之前的建筑全部买满，放一次 Grand Balance，另两种也这样重复。
  - **DDC4**：动作快一点，**不要买 Hall of Balance**，让 Grand Balance 保持 20 秒。
  - 离线挂 5 小时德鲁伊和 5 小时无面者，会解锁 A305 和 S305，还没做的尽快做。C305 暂时不重要，迟早解锁就行。
  - 到转生宝石时，把 E320 换成 E270，解锁 W320。
- **R26**
  - 要解锁 **A300**。有了 C330 会快一点，但不多。用 DDDD，买齐所有回魔和魔上限研究（尤其 D300），约 10 分钟。**C340 先别买。**
  - 德鲁伊现在产量更好。它的最终挑战奖励 **Primal Balance** 很关键：本局产魔达到 320 万才能同时作用 3 个建筑。这个 R 解锁 A300 时就会达到；之后两个 R 用 Mana Fairies 时也记得达到（很快）。
  - Ancient Device 还没挖到就继续试。它给的额外槽位目前不强（R26 德鲁伊只是多了 E250 和 A200），晚几个 R 拿也行。
- **R28**：400 系研究很强（尤其 S400、A400），这个 R 会很快。C400 是很好的 FC 研究。
- **R29**：E425 大幅加强皇家兑换，改回**泰坦**（现在没有随机性了）。用低宝石哥布林拿 S425。
- **R30**
  - 用 FCDD 拿 **E450**（R28 的研究够用），D450 先不管。E450 很强，能一路撑到声望研究。
  - 这时奖杯数肯定够 666 个，去挖**恶魔 1 遗物**。
  - 可以拿 **Van!shment**（离线产能 1e15%）：用不死族，买 A55、A480、W320；需要的话离线一会儿加强 UD9。

## 第 6 部分：声望研究（R32–R39）

- **R32**
  - 挖到 2750 次拿 **Earth Core**。约 e118 宝石时，用妖精血统的妖精 + 矮人（不开研究）解锁**声望研究**。哥布林 build 马上能用，直接冲过转生宝石。
  - 去挖两个新任务遗物：**Flame of Bondelnar**（挖掘 3000 次以上）和 **Horn of the Kings**（3250 次以上）。挖 Horn 可以用 R36+ 妖精 build，把 E330/E200 换成 E270 多挖。有好几个 R 时间，很可能 R32 就两个都拿到。拿到 Flame 后，哥布林 build 带上它能把宝石推得更高。
  - 顺便做 **DNC1–4**（都很简单）。这里默认你已完成 DWC2，**DWC3 先别做**。
- **R33**
  - 低宝石阶段变化很大：有声望研究后卓尔很强，用**精灵血统哥布林**，因为最快配好。回魔很快就够开自动施法。
  - **不要换佣兵。** 约 e50 宝石换无面者血统冲产量；很快就能买 FCGB 低宝石 build 的研究；约 e80 换另一套 FCGB build。
  - e90 宝石白拿 **No Recruiting**。R 末尾做 **DNC5**。新研究解锁暂时不管。
- **R35**：挂时间的研究都齐了，集中解锁：
  - 打一局长的不死族：解锁 **DWC3–5**、W625、S525。
  - 用 FCFR 解锁 D205、C340、D525、D625（顺带 D400、E575）。
  - 再用中立阵营待一会儿解锁 D450。
  - 后面的 build 默认你已有 Horn 和 Flame。高宝石阶段改用**妖精**，更强。
- **R36**：拿 A0 最后两个隐藏奖杯。
  1. **Stoic Resistance**（第一局退位时达到 1e27 宝石，失败就下个 R 再试）
     - 最佳组合是**矮人血统不死族**（恶魔也行）。持续挖掘加强矮人血统。
     - 先买齐 Heritage，再买齐卓尔升级。
     - 离线约 10 分钟加强 UD9、UD6，期间只自动施放 Night Time，让离线活跃时间最大化。
     - 拿到 Planned Autocasting 后，最后一段用银色自动施法预设。
     - 目标 5e65 钱币，最后一个关键升级是 Blackguards（加强 Evil Fortress）。整局约 20 分钟。
  2. **Iron Rush**（5 分钟内 725 个 Iron Stronghold，不用 gem power 和 R power），在 R 末尾做：
     - 先快速打一局中立，提高中立建筑数。
     - 去选项关掉"全部购买升级"，才能用全部购买。
     - 用不死族血统，靠 Stoic Resistance 买得起中立。尽量多买建筑升级来增加助手，点几下赚钱；可以放几个法术，**但绝不要放 Gem Grinder**。完成过 Faction Run 才能足够快地拿到中立阵营的 FC。
     - 换德鲁伊，会快很多。继续买，到 e40 钱币不难；法术可以放，但要留魔。
     - 最后放一次大连招，一边连放 TC 一边买建筑和升级，在法术结束前到 725 个 Iron Stronghold。

  到这里你应该有 **47 个隐藏奖杯**，也就是 A0 能拿的全部（Equality 除外）。
- **R37**：每个阵营再加一个最终研究，很容易拿，但暂时用不上。到这里除了可能还缺 C305，所有研究都已解锁。
- **R37–R39**：只剩刷宝石，每个 R 慢一点，但不会太慢。

## 第 7 部分：A0 之后（Ascension）

Ascension（飞升）会把所有产能倍率开 0.1 次方，数字大幅缩小；建筑数和挖掘次数会调整，让 R40 和 R39 的水平差不多。

另外还有几个变化：
- **免费重置挖掘**：不再花红宝石，第一次试试会拿一个奖杯。每个 R 大约能重置 5 次才变贵；价格每个 R 重置，也和 R 数有关。
- **Reverse Autocasting**：可以取消法术（R + 点击），轮换法术和刷施法目标会快很多。
- **解锁龙族（Dragon）**：A1 的前几个 R 主要是解锁中立声望阵营龙族。解锁的各个阶段会逐步开放**法术层级（spell tier）**，这是 A1 的新机制。
